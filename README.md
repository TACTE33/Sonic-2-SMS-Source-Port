SONIC 2 SMS: PC PORT

Sonic 2 SMS: PC Port is a Source Port of Sonic the Hedgehog 2 for the "SEGA Master System".
This Port aims to bring Sonic 2 SMS as a Source Port, inspired by how Sonic 3 A.I.R was created.
It is currently a work in progress, as in a bunch of stuff has been mapped ranging from Level Tables and beyond. 

This is NOT related to Sonic 2 SMS Remake, as that this one is highly moddable. Just keeping the game vanilla for offers.
This Port uses ".txts" as scripts to make it's modding less stressful.

//THINGS MAPPED AND PROGRESS//

Things like "audio.txt", "level_table.txt" and, "palette.txt" is complete, but these are just a few, as in a bunch
has been mapped. 30% has been mapped. For Palettes, the Port will use ".pal" files.

//QOL FEATURES//

In this Port, the game will run at 60fps and, 1080p and beyond if you change in the "config.json".
Once you first provide your ROM, the executable  will create "sms.bin". Every Zone or Act you start on will update
this "sms.bin to the latest." That means everytimr you start back up, you'd be on the Zone or Act you exited on. 
The next point of this mod is making Sonic 2 SMS easier to hack. Since the scripts are modular, they would be similar to
how S3AIR does scripts. (NOT Lemon though...)
